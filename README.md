# Heartbreak Posts 💔 (MOCKUP)
Idea dashboard for a Thai creator (IG + TikTok), heartbreak / อกหัก theme, Gen Z edition.
Open `index.html` (or the single-file `dashboard-offline.html`). Tracker numbers are EXAMPLE until you upload your own file;
uploads, saved ideas and Day X ticks stay in your browser (localStorage), nothing is sent anywhere.
Excel reader: SheetJS CE (Apache-2.0) in `vendor/`.
